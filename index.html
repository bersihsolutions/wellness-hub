Supabase Realtime Cloud Setup Guide

Connect your free Supabase project to sync all gratitude notes, votes, and pod bookings live across every office device!

1 Step 1: Execute SQL Script in Supabase Editor

Copy and paste this snippet into your Supabase project's SQL Editor:

-- 1. Create Daily Pulse table
CREATE TABLE IF NOT EXISTS daily_pulse (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  mood text NOT NULL,
  created_at timestamptz DEFAULT now()
);

-- 2. Create Gratitude Notes table
CREATE TABLE IF NOT EXISTS gratitude_notes (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  user_name text NOT NULL,
  recipient text NOT NULL,
  message text NOT NULL,
  tag text NOT NULL,
  created_at timestamptz DEFAULT now()
);

-- 3. Create Quiet Zone Bookings table
CREATE TABLE IF NOT EXISTS quiet_zone_bookings (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  slot_time text NOT NULL,
  pod_name text NOT NULL,
  booked_by text NOT NULL,
  created_at timestamptz DEFAULT now()
);

-- Enable RLS and public policies
ALTER TABLE daily_pulse ENABLE ROW LEVEL SECURITY;
ALTER TABLE gratitude_notes ENABLE ROW LEVEL SECURITY;
ALTER TABLE quiet_zone_bookings ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Public Read Pulse" ON daily_pulse FOR SELECT USING (true);
CREATE POLICY "Public Insert Pulse" ON daily_pulse FOR INSERT WITH CHECK (true);

CREATE POLICY "Public Read Notes" ON gratitude_notes FOR SELECT USING (true);
CREATE POLICY "Public Insert Notes" ON gratitude_notes FOR INSERT WITH CHECK (true);

CREATE POLICY "Public Read Bookings" ON quiet_zone_bookings FOR SELECT USING (true);
CREATE POLICY "Public Insert Bookings" ON quiet_zone_bookings FOR INSERT WITH CHECK (true);
2 Step 2: Enable Realtime Replication

In Supabase Dashboard, go to Database > Replication and enable replication for `daily_pulse`, `gratitude_notes`, and `quiet_zone_bookings`.

3 Step 3: Save API Keys in App

Click the "Configure Credentials" button below to input your Project URL and Anon API key.
